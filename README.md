# n8n-nodes-enreach

This is an n8n community node that provides custom nodes for integrating with [Enreach](https://enreach.com) communication services.

[n8n](https://n8n.io/) is a [fair-code licensed](https://docs.n8n.io/reference/license/) workflow automation platform.

## Installation

### Community Node (Recommended)

In n8n, go to **Settings** > **Community Nodes** and install:

```
n8n-nodes-enreach
```

### Manual Installation

```bash
npm install n8n-nodes-enreach
```

## Nodes Included

This package includes two powerful nodes:

### 1. Enreach Trigger
A webhook trigger node that listens for Enreach events with JWT authentication.

**Features:**
- Custom webhook path configuration (UUID auto-generated by default)
- JWT token validation for secure webhook authentication
- Event filtering (chat history, ACD call qualification)
- Automatic webhook registration/deregistration

### 2. Enreach
An action node for sending messages and handling responses through Enreach API.

**Operations:**
- **Send and Wait**: Send a message and wait for user response
- **Send Message**: Send a message without waiting for response

**Message Types:**
- **Text**: Simple text messages
- **Button**: Messages with button options (max 20 chars per button)
- **List**: Messages with list selection (3-10 options)
- **Annotation**: Annotation messages

## Configuration

### Setting up Credentials

1. Create Enreach API credentials in n8n:
   - Go to **Credentials** > **New**
   - Select **Enreach API**
   - Enter your JWT secret key

### Basic Workflow Example

```
[Enreach Trigger] → [Enreach (Send and Wait)] → [Process Response]
```

## Usage Examples

### Send a Simple Text Message

```javascript
{
  "operation": "sendMessage",
  "type": "text",
  "text": "Hello! How can I help you today?"
}
```

### Send Interactive List

```javascript
{
  "operation": "sendAndWait",
  "type": "list",
  "text": "Please select an option:",
  "buttonTitle": "Choose one",
  "options": [
    { "id": "1", "title": "Option 1", "description": "First choice" },
    { "id": "2", "title": "Option 2", "description": "Second choice" },
    { "id": "3", "title": "Option 3", "description": "Third choice" }
  ]
}
```

### Send Button Options

```javascript
{
  "operation": "sendAndWait",
  "type": "button",
  "text": "Do you want to continue?",
  "options": [
    { "id": "yes", "title": "Yes" },
    { "id": "no", "title": "No" }
  ]
}
```

## Features

### Auto-Detection
The Enreach node automatically detects JWT and callback URL from:
1. The previous node in the workflow
2. Any "Enreach Trigger" node in the workflow
3. A specifically named trigger node (configurable)

### Wait Configuration
For "Send and Wait" operations, you can configure timeout:
- **No limit**: Wait indefinitely
- **Time interval**: Wait for specified duration (seconds/minutes/hours/days)
- **Specific date/time**: Wait until a specific date and time

### Error Handling
- Comprehensive error messages with clear descriptions
- Retry logic with exponential backoff for transient failures
- Continue on fail option with error output

## Limitations

### Message Limits
- **Text**: Max 1024 characters for list/button types
- **Button Title**: Max 20 characters
- **Option ID**: Max 256 characters
- **List Options**: Minimum 3, maximum 10 options
- **Button Title (for buttons)**: Max 20 characters

### API Rate Limits
The node includes automatic retry logic with exponential backoff for rate limit handling.

## Troubleshooting

### Common Issues

1. **"Trigger node not found"**
   - Ensure the Enreach Trigger node exists in your workflow
   - Check the trigger node name matches exactly
   - Verify the nodes are connected properly

2. **"JWT validation failed"**
   - Verify your JWT secret is correct
   - Check the algorithm matches your configuration (HMAC SHA-256)
   - Ensure the token hasn't expired

3. **"Message too long"**
   - Text messages for list/button types are limited to 1024 characters
   - Button titles are limited to 20 characters
